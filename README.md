## Featured Projects

### Conecta Talento + Conecta Pass

Event platform for a career-fair-style event, covering four roles (participants, companies, universities, organizers) end to end.

- Focus: QR-based credentials, consent-gated data sharing, real-time capacity tracking, multi-role auth
- Tools: Next.js, TypeScript, PostgreSQL, Drizzle ORM, Vercel

### Math2Braille

Accessibility-focused project aimed at helping visually impaired students access high-quality mathematical content.

- Focus: mathematical accessibility, Nemeth Braille, assistive technology
- Role: Co-Founder / Technical Contributor
- Built alongside [Edwin Hurtado](https://github.com/Hedurtado)
